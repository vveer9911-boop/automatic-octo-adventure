# Component Specifications (`replica/design/components.md`)

Generated by `/replica-design` from `replica/recon.md` and `replica/screens/appstore_1.png`–`appstore_7.png`.
All components use open icons (`lucide-react`), open fonts (`Inter` + `JetBrains Mono`), procedural CSS/SVG card artwork, and design tokens from `tokens.css` (zero raw hex).

---

## 1. `FocusCard`
The signature metallic/skinned Screen Time Wallet card that holds the user's earned Credits.

```
FocusCard
  variants  metal-classic, metal-obsidian,
            circuit-dark, circuit-silver, circuit-stripe,
            weave-carbon, weave-cobalt, weave-crimson,
            urban-gold, urban-sticker, urban-graffiti
  sizes     hero (100% width, aspect-ratio 1.586:1, radius card 22px),
            vertical-gallery (128x200px for S13 Card Studio carousels),
            mini-badge (44x28px for S15 Leaderboard rows and S09 Withdraw pill)
  states    default (integer or 2-decimal credit readout + "= Xm screen time"),
            live-ticking (2-decimal streaming readout e.g. "15.02 credits" with subtle cyan aura glow),
            interactive-tilt (3D pointer/gyroscope perspective tilt on S04/S13),
            locked-preview (shows Pro lock badge in S13 Card Studio for non-premium users)
  tokens    bg card-metal (or procedural SVG pattern per skin), text on-card-metal (or text on dark skins),
            radius card, shadow card, font sans (balance) + emboss (custom label)
  a11y      role="region" aria-label="Focus Card Balance: X credits, equal to Y minutes of screen time"
            live-ticking state uses aria-live="polite" throttled to whole-minute announcements
  used on   S01, S04, S06, S09, S13, S14, S15, S16
```

## 2. `NativeAdBannerCard`
Tasteful, dark-themed native advertisement container for Free-Tier users (automatically hidden when `is_premium = true`). Replaces the original's coupon banner on `S06` and post-session coupon modal on `S08`, plus a single compact slot on `S04`.

```
NativeAdBannerCard
  variants  focus-top-pill (68px height, pill/rounded-lg container at top of S06 Active Focus screen),
            post-session-card (140px height, featured sponsored card on S08 Session Complete screen),
            dashboard-compact (88px height, subtle dark surface card below action row on S04 Wallet Home)
  sizes     full-width within mobile container (max 390px), fixed height per variant to guarantee 0 CLS
  states    loading (subtle shimmer skeleton inside fixed-height frame),
            filled-ad (Sponsored badge, advertiser icon, headline, 1-line body, CTA pill, "Remove Ads" micro-link),
            fallback-house-ad (promotes upgrading to Ad-Free Pro when offline),
            hidden-for-premium (renders null when is_premium is true)
  tokens    bg surface, border border, text text, subtitle text-muted, badge surface-elevated,
            radius lg (focus-top-pill & dashboard-compact) / card (post-session-card), shadow surface
  a11y      aside element with aria-label="Sponsored Advertisement", clear "Ad" badge, keyboard-focusable CTA and "Remove Ads" button
  used on   S04, S06, S08
```

## 4. `NumericKeypad` & `QuickDurationPills`
The custom duration entry control on `S09` (`Withdraw`) supporting 1-minute minimum withdrawals up to 480 minutes.

```
NumericKeypad
  variants  withdraw-entry (quick duration pill bar + 3x4 digit grid)
  sizes     quick pills: height 38px, radius pill; keypad cells: height 60px, 3-column grid
  states    default, pill-selected (bg accent, text on-accent), key-pressed (bg surface-elevated),
            insufficient-balance-error (shake animation + danger helper text when requested credits > balance)
  tokens    active pill: bg accent, text on-accent; inactive pill: bg surface-elevated, text text-muted;
            keypad digits: font xl/600, text text
  a11y      quick pills use role="radiogroup" / aria-pressed; keypad buttons have explicit aria-label ("1", "Backspace") and support physical keyboard digit entry
  used on   S09
```

## 5. `AppBlockRow` & `CategoryFilterChips`
Interactive rows for toggling locked apps, categories, and website domains on `S02` and `S10`.

```
AppBlockRow
  variants  app-item (app icon + name + category subtitle + lock switch),
            domain-item (globe icon + domain string + delete/lock switch),
            category-master (category icon + count of apps + master lock toggle)
  sizes     row height 64px, radius md
  states    locked (switch ON, lock badge visible), unlocked-temporarily (amber countdown badge during active withdrawal),
            unlocked-off (switch OFF), disabled-by-strict-session (cannot unlock without withdrawing credits)
  tokens    bg surface, border border, text text, subtitle text-muted, active switch bg accent
  a11y      <button role="switch" aria-checked="true|false"> linked via aria-labelledby to the app name
  used on   S02, S10
```

```
TransactionLedgerRow

            starting-bonus (+credits in success green),
            withdraw-spend (-credits in primary text),
            motion-penalty (-credits or 0.00 forfeited in danger red)
  sizes     row height 68px, grouped under sticky date headers
  states    default, expanded-detail (shows session mode, duration, exchange rate, and timestamp)
  tokens    bg surface, border border, positive delta text success, spend delta text text, penalty delta text danger,
            timestamp & balance-after text-muted, font mono for credit amounts
  a11y      semantic list item with full screen-reader summary ("Focus Session Earned +15.00 credits, balance 30.00 credits")
  used on   S12
```

## 10. `BottomTabBar` & `AppShieldOverlay`
Primary mobile shell navigation (`Wallet`, `Blocks`, `Ranks`, `System`) and the full-screen Android blocker shield (`S10`) when opening a locked app with 0 unlocked minutes.

```
BottomTabBar
  variants  4-tab mobile dock (Wallet, Block List, Ranks, System)
  sizes     height 68px, fixed bottom inside mobile shell
  states    inactive (text-muted), active (text text + top indicator pill), hidden (on full-screen S06 Focus, S07 AR Vault, S09 Withdraw)
  tokens    bg surface, border border, active text, inactive text-muted
  a11y      <nav aria-label="Primary"> with aria-current="page" on active tab
  used on   S04, S10, S12, S13, S14, S15
```
